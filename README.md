# Реласкоп — перечёт лесосек методом круговых реласкопических площадок (КРП)

Offline Android-приложение для таксации лесосек: живая камера + виртуальный полупрозрачный
прицел вместо физического реласкопа. Физический реласкоп (прорезь 2 см, цепочка 1 м)
используется только один раз — для калибровки камеры конкретного телефона.

Метод: критическое отношение ширины прорези к расстоянию 1:50 → угловой коэффициент (BAF) = 1 м²/га,
критический угол ≈ 1,146°. Дерево учитывается, если ствол на высоте 1,3 м перекрывает прорезь
(выглядит шире её).

## Возможности
- Расчёт числа площадок по Таблице 1 (категория древостоя, полнота, площадь; < 3 га — учёт не проводится).
- Полные (1, 360°) и половинные (0,5, 180°) площадки.
- Виртуальный квадратный прицел-прорезь на экране; сигналы цветом:
  зелёный — ствол шире прорези (учитывается), красный — уже (не учитывается),
  жёлтый — равен в пределах ±5% (повторить измерение), белый контур — границ не видно.
- Решение о записи принимает пользователь кнопкой «УЧЕСТЬ ДЕРЕВО (СТВОЛ ШИРЕ ПРОРЕЗИ)».
- Породы: сосна, берёза, лиственница, ель, кедр; категории: деловые/дровяные.
- Автосохранение сессии (JSON) — переживает перезапуск приложения.
- Итоговая Таблица 0 на экране; экспорт CSV и XLSX через системное окно «Сохранить как…»
  (любая папка, Telegram, Диск и т.п.).
- Работает полностью без интернета.

## Требования
- Android 7.0+ (minSdk 24). Базовая модель: Xiaomi Redmi Note 11; на любом другом телефоне
  достаточно заново пройти калибровку (калибровка привязана к модели устройства и
  автоматически сбрасывается при смене модели).
- Разрешения: камера, вибрация.

## Сборка
1. Android Studio (Hedgehog или новее), открыть папку проекта, Sync Gradle.
2. Проверенная связка версий: **AGP 8.5.2, Kotlin 1.9.24, Gradle 8.7, JDK 17**.
    - `gradle/wrapper/gradle-wrapper.properties`: `distributionUrl=.../gradle-8.7-bin.zip`
    - Если терминал ругается `JAVA_HOME is not set` — добавить в `gradle.properties`:
      `org.gradle.java.home=C:/Program Files/Android/Android Studio/jbr`
    - В Settings → Build Tools → Gradle выбрать Gradle JDK = 17 (jbr-17).
3. Иконка приложения: `res/mipmap-*/ic_launcher(.png)` (красный реласкоп на фоне леса),
   прописана в `AndroidManifest.xml` (`android:icon`, `android:roundIcon`).
   На Xiaomi после переустановки иконка может обновиться только после удаления приложения
   и перезагрузки телефона (кэш лаунчера).
4. Run на телефон (разрешить камеру).

## Калибровка (один раз на модель телефона)
1. Закрепить красный реласкоп на цепочке 1 м от камеры, фон контрастный, выступы с прорезью
   видны полностью.
2. КАЛИБРОВКА → «Сделать фото» → приложение находит пластину и прорезь, рисует зелёные линии.
3. При необходимости подправить границы ползунками «Левая/Правая граница» (±10% ширины кадра).
4. «Подтвердить» → сохраняется k = ширина прорези / ширина кадра для данной модели.
5. «Переснять» полностью убирает старый кадр и возвращает живой превью.
   Размер виртуального прицела на экране перечёта = k × ширина превью (не зависит от разрешения).

## Перечёт
1. Стартовый экран: площадь (га), категория (чистые ≥80% / смешанные ≤70%),
   полнота (0,9–1,0 / 0,6–0,8 / 0,3–0,5) → «Требуется площадок: N» (Таблица 1).
   Площадь < 3 га — учёт не проводится.
2. НАЧАТЬ ПЕРЕЧЁТ → выбор типа площадки (полная/половинная).
3. Держать камеру на высоте глаз, прицел наводить на центр ствола на высоте 1,3 м,
   плавно поворачиваться на 360° (или 180°). Приложение НЕ ищет ствол само — оно лишь
   измеряет ширину объекта в центре прицела и сравнивает с прорезью.
4. При зелёном прицеле + вибрации нажать «УЧЕСТЬ ДЕРЕВО» → выбрать породу и категорию.
   Защита от дублей и дисциплина обхода — ответственность пользователя.
5. «Завершить площадку» → следующая; после всех — «ЗАВЕРШИТЬ ПЕРЕЧЕТ ЛЕСОСЕКИ».
6. РЕЗУЛЬТАТЫ: Таблица 0 на экране; «Экспорт CSV» / «Экспорт XLSX» открывают системное
   окно «Сохранить как…» (имя файла `Таксация_ГГГГ-ММ-ДД_ЧЧ-мм.*`).

## Настройка детектора (при необходимости)
- Порог контраста границы: `findEdge`, `d > 28` (уменьшить до 20 для тёмных стволов).
- Стабильность сигнала: 6 кадров подряд (`rawCount >= 6`).
- Фильтры «вертикальности»: границы в ≥70% строк зоны ±2,5 прорези; стабильность ширины ±25%;
  непрерывность границ (наклон ствола допускается).

## Известные ограничения
- Детектор — эвристика (baseline): вертикальные объекты (трубы, столбы, оконные рамы)
  геометрически неотличимы от ствола; окончательное решение принимает оператор кнопкой.
- Для боевой точности заменить реализацию `TrunkDetector` на ML-модель сегментации стволов
  (TFLite) — интерфейс и остальной код не меняются.
- Если превью повёрнуто не так на нестандартном устройстве — поменять ветви 90/270
  в `YuvGray.rotate`.

## История изменений
- Отказ от панорамы и материально-денежной оценки: только перечёт по породам на живой камере.
- Виртуальный прицел вместо физического реласкопа; калибровка по фото с цепочкой 1 м.
- Запись дерева только по кнопке пользователя (убрано авто-открытие диалога).
- Добавлены фильтры ложных срабатываний (автомобили, ручки, шкафы и т.п.).
- Исправлены: масштаб координат калибровки, «Переснять», конфликт `View.getY()`,
  экспорт в скрытую папку (теперь «Сохранить как…»), сброс калибровки при смене модели.
- Добавлена иконка приложения; настроены стабильные версии сборки (AGP 8.5.2 / Gradle 8.7 / JDK 17).
